# architecture/contracts

Shared interface and numerical definitions, clearly distinguishing accepted project agreements from examples or proposals.

Existing implementation or reference files are present; see [setup and example scope](../SETUP.md).

This is a suggested home for work supporting the [charter](../CHARTER.md) and
[objectives](../OBJECTIVES.md). The team can reorganize or extend it as its work
develops. A directory’s presence does not assign a task or require an artifact.

## Existing illustrative contract

[mac-v0.json](mac-v0.json) defines the supplied signed INT8 / INT32 MAC example:
wraparound accumulation, asynchronous active-low reset, and clear before enable.
It is an example-level contract, not an adopted command set or a complete
accelerator specification. Future shared project contracts are choices for the
participating teams as they develop their work.
